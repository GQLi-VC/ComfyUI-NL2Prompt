## 3. 设置窗口化（v3 核心）

**不使用节点内折叠区**。两个节点各自带一个「⚙ 设置」按钮，点击弹出**独立窗口**。

- 实现：`document.body` 挂载 `position:fixed` 全屏遮罩 + 居中面板（`z-index:10000`），参考 `easyuse_anima_settings.js` 的 `SettingsWindow` 结构；遮罩点击 / `Esc` / 关闭按钮三种关闭方式
- 窗口内 Tab 分组；窗口开关状态**不写入** workflow
- 数据仍存 hidden holder JSON（与动态行同一序列化真源），窗口只是它的编辑器
- 窗口打开时 `pointerdown` stopPropagation，避免触发画布拖拽

**设置项重新分配**（用户已授权按匹配度调换）：

| 原位置 | 项目 | 新位置 | 理由 |
|---|---|---|---|
| 主节点 更多设置-1 | 文字指定提示词 `\|自然语言\|→Prompt\|` | **主节点窗口 › 标签页「提示词替换」** | 与主节点组装逻辑强绑定 |
| 主节点 更多设置-2 | LLM 系统提示词 + 恢复默认（需确认） | **主节点窗口 › 标签页「系统提示词」** | 决定主节点如何组装，属提示词域 |
| 主节点 更多设置-3 | TopK / TopP / 种子（随机/指定） | **加载LLM 窗口 › 标签页「采样参数」** | 属模型推理参数，随模型走更合理 |
| 加载LLM 设置区 | 温度 / max_tokens / 上下文 / 超时 | **加载LLM 窗口 › 标签页「采样参数/运行」** | — |
| 加载LLM 主项 | 模型类型 / GPU / 路径 / 扫描 / 供应商 / api_key / 模型代号 | **加载LLM 节点正面**（保持可见，因需频繁切换） | 这些是"选模型"，不是"设置" |
| 新增 | 种子显示（每次执行后回填） | 主节点正面小字 + 加载LLM 窗口「采样参数」 | 满足"每次生成写入并显示" |

> TopK 在云端 OpenAI 兼容协议下多数不支持：窗口内云端模式自动灰化并提示。

## 4. 隔离测试环境

**目标**：所有开发验证在项目内独立 ComfyUI 实例完成；用户原有 `<你的ComfyUI根目录>` 全程只读。

```
<项目根>\test_env\
├─ ComfyUI\                 ← 从原目录复制核心（排除 models/custom_nodes/user/output/input/temp/.git）
├─ extra_model_paths.yaml   ← 只读指向 <你的ComfyUI根目录>\models\*
├─ user\default\            ← 独立
└─ start_test.ps1           ← 用原 python：python.exe -s main.py --port 8199 --cuda-device 0
```

- **复用原 Python 环境**（torch cu130 就绪），插件只用标准库 + `requests`，**不装新依赖**，原环境零改动
- `custom_nodes` 只放本插件目录联接，不加载用户现有 100+ 插件
- 端口 **8199**（避开 8188）；测试环境可整目录删除
- 模型经 `extra_model_paths.yaml` 只读引用，**不复制几百 GB 权重**
- A9 验收 = 交付前后原目录文件清单/时间戳无变化
- 最终上线：仅在用户确认后，才把插件联接进原 `custom_nodes` 并新增示例工作流

## 5. 插件结构（3 个节点）

`plugin/comfyui-anima-nl-composer/`，联接到测试环境（原环境仅最终步骤）。

1. `NL2PromptComposer`「自然语言提示词」：NL 输入 + 角色行 3 列 + 风格行 2 列 + 两个添加按钮 + ⚙ 设置窗口；输出 `positive` / `negative` / `text` / `lora_stack` / `debug`
2. `NL2PromptLoadLLM`「加载LLM」：模型类型、GPU 名、路径、扫描下拉、供应商、base_url、api_key、模型代号 + ⚙ 设置窗口；输出 `LLM_MODEL`
3. `NL2PromptLoRAStack`「LoRA 堆栈加载」：`MODEL+CLIP+lora_stack → MODEL+CLIP`

**序列化契约**（hidden holder JSON）：

```json
{"character_rows":[{"name":"","trigger":"","outfit_hint":""}],
 "style_rows":[{"name":"","trigger":""}],
 "text_map":[{"find":"","prompt":"","target":"positive"}],
 "system_prompt":"", "sampling":{"top_k":40,"top_p":0.9,"seed":-1},
 "ui":{"collapsed_main":false}}
```

## 6. 后端契约

- 节点标准 `INPUT_TYPES / RETURN_TYPES / FUNCTION`；`IS_CHANGED` 参数哈希（`seed=-1` 返回时间戳）
- 路由：`GET /nl2prompt/scan_gguf?path=` · `GET /nl2prompt/gpus` · `POST /nl2prompt/secret` · `GET /nl2prompt/secret_status`（只回 configured）· `GET /nl2prompt/default_system_prompt` · `POST /nl2prompt/runtime/{start,stop,status}`
- 本地运行时：懒启动 `llama-server -m <gguf> --port <自动> -ngl 99 -c <ctx>`，env `CUDA_VISIBLE_DEVICES=<gpu>` 精确绑卡；`/health` 就绪轮询 ≤120s；同模型同卡复用；退出 terminate
- 云端：OpenAI 兼容 `/chat/completions`；`deepseek / openai / anthropic / 自定义` 映射；Anthropic 原生协议差异在 `debug` 明示
- api_key：环境变量 `ANIMA_LLM_API_KEY` 优先 → 插件 `data/secrets.json`（不入 workflow、入 `.gitignore`）；路由绝不回显
- 组装：NL → 角色行（激活词+装扮）→ 风格行 → 文字替换 → 模板拼 positive/negative → 可选 LLM 重写（JSON 契约）→ 失败回退模板并记 `debug.reason`；多服装只注入当前装扮，其余进 negative 抑制

## 11. 风险与回滚

| 风险 | 处置 |
|---|---|
| 前端 API 变动 | 只复刻已验证范式，不碰私有 API；UI 异常时后端默认值仍可用 |
| 设置窗口被画布遮挡/Esc 冲突 | 固定 z-index + 焦点陷阱；`Esc` 仅关闭窗口 |
| 动态行/窗口数据丢失 | hidden holder 单真源 + `onConfigure` 迁移兜底 + 保存重开测试 |
| 测试环境与正式环境差异 | 同版本复制核心 + 同 python + 同模型只读路径；最终在原环境各跑一次关键用例 |
| 隔离环境占用空间 | 仅核心代码（约 200–400MB）+ 无模型副本；可整目录删除 |
| `anima-base-v1.0` 不存在 | 默认 `anima-preview3-base`，README 标注可切换 |
| LoRA 底模不匹配 | `base_model` 校验，`(Illustrious)/(SDXL)` 拒绝并告警 |
| api_key 泄漏 | 环境变量/secrets 文件，路由不回显，workflow 内 grep 校验 |
| 3060 OOM | 降分辨率/步数；TE 拆卡需 MultiGPU（备选，不默认） |
